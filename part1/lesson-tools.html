Tools

Tools let the agent act instead of only talk. Yours needs two: an RPA workflow that writes the finished claim into Data Fabric, and an IXP project that extracts data from the uploaded claim document.

8

Add the RPA workflow tool

Under Tools click Add tool, then choose RPA workflow in the Toolbox.

Search for Workflow_Latest and select Updated_SaveDocumentData Workflow_Latest from the Claim Intake Process folder.

Keep the name, type the description below, and review the input arguments — each one needs a clear description so the agent knows what to pass.

Description
Run the Updated_SaveDocumentData Workflow_Latest tool to write the record in IntakeClaimEntity
ArgumentDescription
in_ClaimIDUnique claim ID generated by the agent
in_PolicyNumberPolicy number of the claimant
in_CustomerNameFull name of the claimant
in_ClaimAmountTotal claim amount in USD
in_IncidentTypeType of incident
in_IncidentDescriptionDescription of the incident
in_ClaimFileUploaded claim file, or null if skipped
in_PolicyStatusPolicy status
in_CoverageTypeCoverage type
in_CoverageLimitCoverage limit
📝 Note
This is the terminal write step: the system prompt makes the agent call it exactly once, and only after the user replies Submit.
Added the RPA workflow tool Updated_SaveDocumentData Workflow_Latest.
Entered the tool description and checked every argument description.
9

Add the IXP tool

Click Add tool again and choose IXP (Preview) — schema-driven data extraction from documents.

Search for claim and select ClaimsProcessing_DocumentProcessing_IXP.

Leave the project name, open the Model dropdown and choose live, then type the description. The attachment input is bound to the file the user uploads in chat.

Description
IXP project that extracts data from claim PDF documents
💡 What it extracts
The system prompt's DOCUMENT VALIDATION section calls this tool to pull PolicyNumber, CustomerName, DateOfDocument, IncidentType and TotalPayable from the upload, which the agent compares with the confirmed policy record to compute the document match score.
Added the IXP tool ClaimsProcessing_DocumentProcessing_IXP with Model = live.
Entered the tool description.
