Conversational Agent

Build a conversational agent that helps a user submit an insurance claim intake using UiPath Apps and Agents.

Overview

In this module, you will create a new UiPath project and build a conversational agent — an agent designed to interact with users in real time. Your agent will form the front door of the Insurance Claim Approval Process: it collects claim details directly from the claimant through a chat-style interface, laying the foundation for the automation you'll extend in later modules of this workshop.
