Insurance Claim Approval Process

An end-to-end, hands-on workshop for building agentic automation on UiPath — using a real-world insurance claim approval process as the running example. You'll progress from a conversational intake agent, to an autonomous fraud agent, to a code-first settlement agent, and finally to full orchestration with Maestro.

What you'll build

This workshop takes you from zero to a working, agentic automation solution for a real insurance claim process. Rather than treating each UiPath capability in isolation, every module builds toward the same use case — an Insurance Claim Approval Process — so you experience how conversational agents, orchestration, autonomous agents, and coded agents fit together in a single enterprise-grade solution.

By the end of the workshop, you will have built a conversational agent that captures claim intake through UiPath Apps, an autonomous agent that detects fraudulent claims, and a coded agent that calculates settlements — and orchestrated all of them, with a human review and GenAI-written emails, in a Maestro BPMN process.

What you will learn

✓
Module 1 · Conversational Agent — build and deploy a claim-intake agent with contexts and tools, and embed it in an app.
✓
Module 2 · Fraud Agent — create and evaluate an autonomous agent that detects potentially fraudulent claims.
✓
Module 3 · Coded Agent — package and publish a Python settlement agent using the UiPath SDK.
✓
Module 4 · Maestro — design the end-to-end claim approval process in Maestro BPMN and wire everything together.

Key concepts

  • Conversational Agent — an agent that interacts with users in real time to collect information, such as claim details, through a chat-style interface.
  • Maestro — UiPath's orchestration platform for coordinating humans, robots, and AI agents across long-running business processes, using either BPMN or Flow.
  • Agent Builder — the low-code experience for designing autonomous and conversational agents directly in Studio.
  • Coded Agent — an agent authored in Python or another SDK-supported language, packaged and published to Orchestrator like any other automation.
  • HITL (Human-in-the-Loop) — checkpoints where a human reviews or approves an agent's decision before the process continues.
💡 Prerequisites
Access to UiPath Studio Web on your assigned tenant, and a UiPath Automation Cloud account. No prior agent-building experience required — each module builds on the last.
