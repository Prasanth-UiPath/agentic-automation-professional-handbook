Agent Builder

Build the Fraud Detection Agent — a low-code autonomous agent that scores an insurance claim for fraud risk and hands back a structured verdict, with no chat interface involved.

Overview

So far, you've built the two ends of the process. In Module 1, the Claim Request Agent collected a claim from the claimant and saved it to Data Fabric. In Module 2, you designed the Insurance Claim Approval Process in Maestro — a BPMN flow that starts the moment that claim record is created, downloads its supporting document, and routes it to a supervisor for review. What that flow doesn't have yet is the piece that decides how risky a claim looks before a human ever sees it.

That's the job of the Fraud Detection Agent you'll build in this module. Unlike the Claim Request Agent, this one never talks to a person — it's an autonomous agent: given the complete claim record (which Maestro has already read from Data Fabric), it applies a fixed set of fraud-scoring rules and returns a structured result (a risk score, a verdict, a routing instruction, and a neutral status email) for Maestro to act on.
