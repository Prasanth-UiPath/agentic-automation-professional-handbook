Module 3 · Coded Agent

Coded Agent

Full Python freedom via an open-source SDK — packaged, published, and run under the same enterprise governance as every other UiPath automation.

Overview

In this module, you'll learn what a Coded Agent is — agent logic written entirely in Python, using the open-source UiPath SDK — and why enterprises are adopting them alongside low-code agents. You'll then build a real one: a Settlement Coded Agent, a pure-Python, deterministic agent that settles insurance claims using simple business rules, with no LLM involved at all. By the end, you'll have scaffolded, written, tested, packaged, published, and invoked a coded agent under full UiPath governance.

💡 An LLM is optional
The Settlement Agent you build in this module is pure deterministic logic — no model calls. Coded agents are just as useful for auditable business rules as they are for LLM reasoning.
📝 Naming
Name your project folder and agent Settlement_CodedAgent_your_name (replace your_name with your own name, no spaces). In Module 4 you will select this published agent in the Maestro process.
