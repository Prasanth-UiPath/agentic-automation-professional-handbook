You Built the Fraud Detection Agent

A quick recap of the autonomous agent you just created.

What you did

You created a low-code autonomous agent, gave it a single object input (in_ClaimData — the complete claim record Maestro already retrieved) and a structured output covering claim details, fraud analysis, a suggested customer email, and a routing status. You wrote a system prompt that encodes a deterministic, nine-rule fraud-scoring model and a matching classification/routing scheme, and wired up a short user prompt — with no Data Fabric lookup or tool required.

✓
Created an Autonomous agent named "Fraud Detection Agent"
✓
Defined the in_ClaimData object input and the full output schema
✓
Wrote the system prompt encoding the fraud-scoring rules and routing logic
✓
Wrote the user prompt referencing the complete claim record — no tools required
