You Built the Fraud Detection Agent

A quick recap of the autonomous agent you just created.

What you did

You created a low-code autonomous agent, gave it a single input (in_ClaimData) and a structured output covering claim details, fraud analysis, a suggested customer email, and a routing status. You wrote a system prompt that encodes a deterministic, nine-rule fraud-scoring model and a matching classification/routing scheme, wired up a short user prompt, and connected the one tool the agent needs — Data Fabric's Get Entity Record by ID — to look up the claim it's asked to analyze.
