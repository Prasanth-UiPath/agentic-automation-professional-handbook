Module 3 Complete

You built a Python coded agent and shipped it to the cloud under enterprise governance. Here's your completion checklist.

Completion checklist

Created the project folder and a virtual environment ((.venv) active)
Installed packages and authenticated (uipath auth)
Scaffolded the agent (uipath new agent)
Pasted pyproject.toml and main.py; checked langgraph.json
Initialized (uipath init) and confirmed uipath.json has no "functions" key
Tested locally (uipath run agent --input.json)
Packaged the agent (uipath pack)
Published to Orchestrator (uipath publish)
Invoked the agent (uipath invoke)
Confirmed the Type is not "Function (python)" in Orchestrator → Processes
