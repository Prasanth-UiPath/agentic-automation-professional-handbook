Build the Agent

You'll build a no-LLM coded agent that settles an insurance claim: given an insurance type, coverage, and claim amount, it returns the settled amount using simple business rules. The agent is a small LangGraph graph, built in a Python virtual environment with the uipath CLI. All commands run in Windows PowerShell — you'll edit files with Notepad, never by typing code directly at the prompt. The result publishes as an Agent, not a Function.

The business rules

Eligible insurance types

Must match exactly (case-sensitive):

  • Medical
  • Stolen
  • Theft
  • Water Damage
  • Vehicle
  • Fire

Settlement percentage

  • Full coverage → settle 95% of claim
  • Partial coverage → settle 90% of claim
  • Any other type or coverage → not eligible, settle 0

Decision at a glance

Insurance typeCoverageResult
Medical / Stolen / Theft / Water Damage / Vehicle / FireFull95% settled
Medical / Stolen / Theft / Water Damage / Vehicle / FirePartial90% settled
Anything else—Not eligible (0)
Eligible typeNeither Full nor PartialNot eligible (0)
🏷️ Inputs & outputs at a glance
Inputs — insurance_type (string), coverage (string, "Full" or "Partial"), claim_amount (float)
Outputs — eligible (boolean), settlement_percentage (float), settlement_amount (float), message (string)

Go to a folder you own

Do not work in C:\Windows\System32 or any other system folder — Windows blocks writing there. Use any folder you can write to (Desktop, Documents, a projects folder), in a normal PowerShell window, not Administrator.

PowerShell
cd "$HOME\Desktop"

Create the project folder

Replace your_name with your own name — letters, numbers and underscores only, no spaces (for example Minal or Priya_S). Type the name only; do not add angle brackets.

PowerShell
mkdir Settlement_CodedAgent_your_name
📝 Note
The same name is used in step 3 and in pyproject.toml (step 10: project name, your name, your email).

10

Open pyproject.toml

PowerShell
notepad pyproject.toml

Press Ctrl+A, delete everything, paste the block below, then replace the three placeholders (project name, your name, your email). Save with Ctrl+S and close Notepad. The project name must match the folder name from step 2.

pyproject.toml
[project]
name = "Settlement_CodedAgent_your_name"
version = "0.0.1"
description = "Insurance claims settlement agent"
authors = [{ name = "your_name", email = "your_email" }]
dependencies = ["uipath>=2.0", "uipath-langchain>=0.18.0, <0.19.0"]
requires-python = ">=3.11"
11

Open main.py

PowerShell
notepad main.py

Press Ctrl+A, delete everything, paste the following, then save and close. Nothing in this file needs your name.

main.py
from typing import TypedDict
from langgraph.graph import StateGraph, START, END

ELIGIBLE = {"Medical", "Stolen", "Theft", "Water Damage", "Vehicle", "Fire"}

class Input(TypedDict):
    insurance_type: str
    coverage: str              # "Full" or "Partial"
    claim_amount: float

class Output(TypedDict):
    eligible: bool
    settlement_percentage: float
    settlement_amount: float
    message: str

def settle(state: Input) -> Output:
    pct = 0.0
    if state["insurance_type"] in ELIGIBLE:
        if state["coverage"] == "Full":
            pct = 95.0
        elif state["coverage"] == "Partial":
            pct = 90.0
    amount = round(state["claim_amount"] * pct / 100, 2)
    return {
        "eligible": pct > 0,
        "settlement_percentage": pct,
        "settlement_amount": amount,
        "message": "Claim settled" if pct > 0 else "Claim not eligible",
    }

builder = StateGraph(Input, output_schema=Output)
builder.add_node("settle", settle)
builder.add_edge(START, "settle")
builder.add_edge("settle", END)
graph = builder.compile()
ℹ️ How it works
The agent is a small LangGraph graph: a single settle node between START and END. Input and Output define the contract, and graph is what UiPath discovers. There is still no LLM — the logic is fully deterministic.
12

Check langgraph.json

PowerShell
Get-Content langgraph.json

It should point to ./main.py:graph. If it does not, run notepad langgraph.json, replace the contents with the block below, and save.

langgraph.json
{
    "graphs": {
      "agent": "./main.py:graph"
    }
}
13

Initialize the project

PowerShell
uipath init
14

Check uipath.json

PowerShell
Get-Content uipath.json
⚠️ No "functions" key allowed
uipath.json must NOT contain a "functions" key — that key makes it a Function instead of an Agent. If it does, run notepad uipath.json, delete that block, save, and run uipath init again.
15

Create the test input

PowerShell
'{"insurance_type": "Theft", "coverage": "Full", "claim_amount": 10000}' | Set-Content input.json
16

Test locally

PowerShell
uipath run agent --input.json

Expected: eligible true, settlement_percentage 95.0, settlement_amount 9500.0.
