Module 2 · Fraud Agent

Fraud Agent

Build an autonomous agent that scores insurance claims for fraud and tells Maestro where each claim should go next.

Overview

In this module you build the Fraud Detect Agent with Agent Builder: define its input and output arguments, write its system and user prompts, and validate it against a 10-claim evaluation set.

📝 Naming
Name your agent Fraud Detect Agent_YourName (replace YourName with your own name).

What you will do

✓
Create an autonomous agent and define its input / output schemas.
✓
Write the system prompt and user prompt that drive fraud scoring.
✓
Import and run an evaluation set of 10 sample claims.
