Evaluate the Agent

An evaluation set runs the agent against many sample claims at once so you can check that scores, verdicts, and routing actions behave as expected before Maestro depends on it. The set provided contains 10 claims from a clean claim to a critical multi-indicator one.

6

Import the evaluation set

Download the evaluation set below. In the agent tree click Evaluation Sets, then Create → Import.

Fraud_Agent_Evaluation_Set.json — 10 sample claims with their expected outputs.
⬇ Download

In the Import datasets dialog choose Upload file and select Fraud_Agent_Evaluation_Set.json.

Downloaded Fraud_Agent_Evaluation_Set.json.
Imported it via Evaluation Sets → Create → Import → Upload file.
7

Run the evaluation

The imported set appears as Fraud Agent Claims Evaluation (copy) with 10 evaluations. Click Run and review the results — compare each claim's fraud score, risk level, verdict, and routing action with what you expect.

📝 Note
The "(copy)" suffix is added automatically on import. A "Default Evaluation Set" may also be listed — ignore it. No evaluators are attached to the imported set, so review the outputs yourself.
💡 Optional: single-claim debug
You can also click Debug and paste a single claim to inspect one run in detail. A sample is provided: Test_Claim_Data.txt. Its field names differ slightly from the Data Fabric names used in the evaluation set, so prefer the evaluation set for scoring checks.
