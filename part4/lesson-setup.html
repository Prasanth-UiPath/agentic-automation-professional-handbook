Set Up the Process

The Maestro BPMN process ties everything together: it starts when a claim is ready for review, calls your Fraud Detect Agent, downloads the claim document, sends the claim to a supervisor, branches on the decision, runs your Settlement Coded Agent, and sends the notification emails.

⚠️ Before you start
Make sure these are ready: your Fraud Detect Agent (Module 2) and your Settlement Coded Agent (Module 3) are published; the Supervisior_ClaimValidation-App_Latest action app is already deployed on the tenant (you will import it, not build it); and the IntakeClaimEntity entity exists in Data Fabric.
1

Create the Maestro BPMN process

From the Start building dialog in Studio Web choose Maestro BPMN — it lets you design a business process on a BPMN canvas, as opposed to Maestro Flow, Agent or RPA Workflow.

Name the solution and the process Insurance Claim_MAESTRO_YourName (replace YourName with your own name).

Created a Maestro BPMN project named Insurance Claim_MAESTRO_YourName.
2

Import the BPMN file

Rather than drawing the diagram, import the ready-made process. Download it, then in the Explorer right-click your Maestro BPMN item, choose Add to project, and select Import BPMN.

Insurance_Claim_Process.bpmn — the complete claim approval process, ready to import.
⬇ Download

In the Import BPMN dialog choose or drop the downloaded .bpmn file.

💡 What you get
The imported canvas already contains every task and the gateway, with their names. The following lessons configure each one in order: Claim Ready for Review, Fraud Detection Agent, Download File from Record Field, Supervisior_ClaimValidation, Send Notify Email to Claimant, Reviewer Action GateWay, SettlementCodedAgent, Generate Approval Email, and Send Approve Email.
Imported Insurance_Claim_Process.bpmn onto the canvas.
