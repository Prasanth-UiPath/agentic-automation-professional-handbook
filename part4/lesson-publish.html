Publish & Run

Package, log in, publish to Orchestrator, and invoke a governed cloud job — the four steps that take your tested agent to production.

9

Package the agent

Bundle the project into a versioned package with codedagent pack.

PowerShell
PS> uip codedagent pack
✓ Package created successfully.
📝 Note
Confirm the package is created successfully before continuing to the next step.
10

Log in to UiPath

Authenticate the CLI against your tenant before publishing. Use the organization and tenant appropriate for your environment — the example below is the one used in testing.

PowerShell
PS> uip login --authority https://cloud.uipath.com --organization tpenlabs -t AgenticPractice
⯈ Opening browser for authentication...
✓ Login successful.
11

Publish the coded agent

Upload the package to Orchestrator with codedagent publish. When prompted to select a package feed, choose the feed required by your environment — in the tested setup, Personal Workspace Feed was selected.

PowerShell
PS> uip codedagent publish
? Select feed:  > Personal Workspace Feed
                  Tenant Feed
⯈ Uploading package...
✓ Package published successfully.
  View it in Orchestrator → Packages
12

Invoke the published agent

Run the published agent in the cloud with codedagent invoke, passing the same input.json file with -f.

PowerShell
PS> uip codedagent invoke Claims_SettlementAgent -f input.json
⯈ Job started in Orchestrator.

output
├── eligible: True
├── settlement_percentage: 95.0
├── settlement_amount: 9500.0
└── message: Settled at 95%

✓ Successful execution.
⚠️ Use the JSON file, not inline JSON
Always invoke with -f input.json. The inline JSON form (passing the object directly on the command line) was tested and failed validation in this environment.
ℹ️ Governance for free
Because it is now an Orchestrator package, the agent inherits RBAC, audit logs, job monitoring, versioning, and one-click rollback — and it can be invoked by any trigger or UiPath process.
Packaged the agent (uip codedagent pack)
Logged in to the correct organization and tenant (uip login)
Published to Orchestrator (uip codedagent publish)
Invoked the published agent with -f input.json (uip codedagent invoke)
Confirmed the job & output in Orchestrator
