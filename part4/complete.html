🎉 You Built a Coded Agent

You built a Python coded agent and shipped it to the cloud under enterprise governance. Here's your completion checklist.

Completion checklist

Created the project folder and scaffolded the agent (uip codedagent new)
Wrote Input/Output models + main() in main.py
Configured uipath.json and pyproject.toml, and removed langgraph.json
Initialized the project (uip codedagent init) and confirmed the entrypoint
Created input.json and tested locally (uip codedagent run … -f input.json)
Packaged the agent (uip codedagent pack)
Logged in to the tenant (uip login)
Published to Orchestrator (uip codedagent publish)
Invoked the published agent with -f input.json (uip codedagent invoke)
Confirmed the job & output in Orchestrator

With a conversational agent, its tools and context, an embedding app, and now a coded agent all built, you're ready to move into orchestration — tying these pieces together with Maestro in the next modules of this workshop.
