# Agentic Automation Professional — ILT Workbook

A static HTML training workbook for the "Agentic Automation Professional" course, walking through building an Insurance Claim Approval Process across 4 modules (Conversational Agent, Maestro/BPMN, Agent Builder, Coded Agent).

## Viewing locally
Open `index.html` in a browser.

## Publishing on GitHub Pages
1. Push/upload the contents of this folder to a GitHub repository (the `.nojekyll` file is already included so GitHub Pages serves the site as-is).
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Pick the branch (e.g. `main`) and folder `/ (root)`, then Save.
5. GitHub will publish the site at `https://<username>.github.io/<repo-name>/` within a minute or two.
